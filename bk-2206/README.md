# 🛡️ SkyNeoSec - vscss

Sitio institucional para **SkyNeo Security**, una empresa dedicada a ofrecer soluciones de ciberseguridad modernas y accesibles.

Este repositorio contiene la estructura web del sitio desarrollada en **PHP**, utilizando **Bootstrap 5** para el layout y **SCSS modularizado** para los estilos personalizados.

---

## 🌐 Estructura del sitio

- `index.php` — Página de inicio
- `servicios.php` — Listado de servicios con tarjetas dinámicas
- `servicio/` — Páginas individuales por servicio
- `includes/` — Componentes reutilizables (`header.php`, `footer.php`, `quienes-somos.php`, etc.)
- `css/` — Estilos compilados desde SCSS
- `assets/scss/` — Estructura modular de estilos (`main.scss`, `components/`, etc.)
- `img/` — Recursos gráficos del sitio (logos, imágenes)

---

## 🎨 Tecnologías utilizadas

- ✅ **PHP**: para estructuración modular de secciones
- ✅ **Bootstrap 5**: grilla y componentes responsive
- ✅ **SCSS**: estilos organizados por componentes
- ✅ **NPM + Sass**: para compilar los estilos
- ✅ **Docker Ready**: opcional, puede levantarse en contenedor
